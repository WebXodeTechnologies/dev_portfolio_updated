## 5. Create the cinematic scroll experience

Use GSAP timelines and ScrollTrigger for:
- Staggered hero typography.
- Cybercity-to-space transitions.
- Scroll-based camera movement.
- Section reveals and restrained parallax.
- A pinned project-storytelling section where appropriate.

Use Lenis for smooth scrolling only if compatible with the existing setup. Integrate Lenis and GSAP ScrollTrigger correctly and avoid competing scroll systems.

Use GSAP context and proper cleanup in React effects. Avoid hydration mismatches, layout shifts and animations that prevent scrolling.
